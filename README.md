## Rescapincho
Proyecto académico enfocado en el desarrollo de un videojuego mediante lógica de eventos, diseño de niveles e interacción entre objetos.

## Descripción

Videojuego 2D desarrollado utilizando programación basada en eventos. El proyecto incluye mecánicas de juego, interacción entre objetos y gestión de estados dentro de la partida.

## Tecnologías utilizadas

- GDevelop
- Programación orientada a eventos

## Características

- Sistema de movimiento
- Interacción entre objetos
- Diseño de niveles
- Gestión de eventos del juego

## Mi aporte

Durante el desarrollo del proyecto me encargué de:

- Implementar la lógica de juego mediante eventos.
- Diseñar e integrar mecánicas principales.
- Configurar colisiones e interacciones entre objetos.
- Realizar pruebas y corrección de errores.
- Colaborar en el diseño y desarrollo general del proyecto.
